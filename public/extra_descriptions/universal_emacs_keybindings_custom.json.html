About this configuration

This is a customized version of Universal Emacs Keybindings by justintanner. The original provides Emacs-style keybindings in applications that do not include them natively.

Changes from the original

  • Applies the keybindings in Sublime Text, Visual Studio Code, and JetBrains IDEs. Vim remains excluded.
  • Supports C-x followed by k to close the current window or tab (⌘W).
  • Extends the selection with ⇧Shift + Page Up when mark is set and ⌥Option + V is pressed.
  • Maps Ctrl + K to select through the end of the line and cut it, then clears mark.
  • Maps Ctrl + W to cut the current selection regardless of whether mark is set.
  • In applications that do not support Ctrl + Shift + B/F/N/P for selection movement (currently Visual Studio Code), maps these keys to Shift + arrow keys while mark is set.
  • Extends the selection by one word with ⌥Option + B or ⌥Option + F while mark is set.
  • Clears mark after pasting with Ctrl + Y.
  • Fixes key repeat for Ctrl + A, Ctrl + D, Ctrl + E, Ctrl + V, and ⌥Option + V by clearing mark when the key is released.
  • Removes the standalone Ctrl + R mapping to reduce shortcut conflicts.
